# Memória do projeto

Atualização: 2026-11-15. Repositório público independente; branch padrão master.

Dois estudos publicados juntos por exportação estática: memória em JavaScript puro e catálogo Angular. As telas usam os componentes/tokens NunesDevs do Figma. Não há backend, login autenticado, API externa ou coleta de dados.

O jogador é um apelido opcional por sessão; renderização sempre textual. Símbolos do jogo são SVGs próprios, fontes locais com OFL e catálogo usa monogramas. Preservar arquivos históricos sem incluí-los automaticamente na distribuição.

Gates e operação estão no README. Evidências geradas não são versionadas. Não confundir build aprovado com publicação real.
