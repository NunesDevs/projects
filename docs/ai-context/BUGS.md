# Correções e limites

Corrigidos: HTML injetável no apelido, shuffle enviesado, clique em carta já aberta, terceira carta durante divergência, timers pendentes após reinício, tempo contado durante pausa, vazamento das cartas na pausa e catálogo sem busca/ordenação funcional.

Limites: nickname não é autenticação; atributos são fictícios; progresso da partida não persiste após recarregar. A chave TLS legada foi removida do índice, mas não do histórico. Fontes/imagens históricas fora da lista de exportação não foram autorizadas para redistribuição.
